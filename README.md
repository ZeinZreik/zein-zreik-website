# Zein Zreik Website

Source repository for Zein Alabdin Zreik's personal portfolio website.

The site presents embedded software, automation, robotics, IoT security, computer vision, and mechatronics work in one place, connecting project experience with public GitHub repositories and professional links.

## Project Snapshot

- Domain: personal portfolio, engineering profile, project showcase
- Focus: presenting robotics, embedded systems, automation, and software work clearly
- Live site: https://zein.zreik.tech
- Portfolio value: gives visitors a central place to understand skills, projects, and contact paths

## What This Project Demonstrates

- Building and maintaining a personal engineering portfolio
- Presenting technical projects for recruiters, clients, and collaborators
- Connecting GitHub repositories, work experience, and contact links
- Turning project history into a clearer professional narrative
